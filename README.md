# OptimServe SDK source preview

SDK-only source prepared for review. It contains no backend, private configuration,
credentials or commercial Apple framework binaries. This package is not published.

The manual Apple compilation workflow runs only in a public repository. It downloads
checksummed dependencies into temporary build storage and uploads no framework
artifacts. Compilation and real device media are not yet qualified. See each SDK's
README and third-party notice. Source adapter licenses do not grant vendor rights.

Android framework bridges depend on agency.optimserve:optimserve-native:0.1.0.
This export includes its source module, not an independent Android application.
